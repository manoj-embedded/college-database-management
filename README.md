# College Database Management System

## About the Project

This project is based on managing college information using SQL. It includes details about students, faculty, departments, courses, attendance and marks. I created database tables, added sample data and wrote SQL queries to work with the data.

## Tables Used

- Departments
- Students
- Faculty
- Courses
- Course Offerings
- Enrollment
- Attendance
- Marks

## Project Files

The project contains the following SQL files:

1. **01_database_schema.sql** – Creates the database tables and defines their relationships and constraints.
2. **02_insert_sample_data.sql** – Adds sample records to the tables for testing the queries.
3. **03_sql_queries_13_to_34.sql** – Contains SQL queries for Questions 13 to 34, including joins, aggregate functions, views, transactions and indexes.

## Technologies Used

- MySQL
- SQL
- GitHub

## How to Run

1. Create a database named `college_db`.
2. Run `01_database_schema.sql` to create the tables.
3. Run `02_insert_sample_data.sql` to insert sample records.
4. Run `03_sql_queries_13_to_34.sql` to execute the queries.

## Purpose

The main purpose of this project is to practice SQL queries and understand how college-related information can be stored and managed using a relational database.

Note:The records used in this project are sample data for learning and testing purposes.
